# 建平中学 · 社团巡礼

这是一个介绍上海市建平中学学生社团的网页，共包含首页和社团总览两个页面。

## 首页

首页展示学校整体形象，内容包括：

- 建平中学校名与“社团巡礼”主题
- 学校简要介绍
- “探索社团”入口
- 建校年份、学生社团数量、在校学生人数等基础数据

## 社团总览页

社团总览页集中展示学校社团，用户可以浏览和查找社团：

- 通过搜索框搜索社团名称、标签或关键词
- 按全部、艺术、科技、体育、文化分类筛选
- 浏览社团卡片，卡片包含封面、名称、分类、简介和招新状态
- 点击“展开更多社团”查看完整社团列表

点击任意社团卡片会打开详情弹窗，展示：

- 社团名称和标签
- 社团详细介绍
- 关键词
- 招新或宣传信息
- 社团海报、联系方式图片和联系文字

## 内容说明

网页中的社团覆盖科技、艺术、体育、文化等方向，每张卡片和详情页使用对应社团的图片展示。暂时没有补充资料的社团会显示“资料整理中”。
